# Git Workflow

> Scope: Reusable Git standard

## Branches

- `main`: production-ready code
- `develop`: active development
- `feature/*`: new features
- `bugfix/*`: bug fixes
- `hotfix/*`: urgent production fixes

## Commits

Write clear commit messages.

Good:

```text
Add member subscription renewal service
```

Bad:

```text
fix stuff
```

## Final Principle

Git history should help future debugging.
