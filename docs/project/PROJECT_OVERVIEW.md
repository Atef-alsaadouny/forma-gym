# Forma Gym Management System

> Scope: Project-specific documentation

## Purpose

Forma Gym Management System is a gym management platform for one gym in the first release, designed so it can later evolve into a Multi-Tenant SaaS product.

## Product Modules

- Public website
- Admin dashboard
- Member management
- Trainer management
- Branch management
- Packages and subscriptions
- Attendance tracking
- Workout programs
- Measurements
- Reports
- Mobile/PWA experience

## Current Strategy

Build for Single Gym now.
Design for Multi-Tenant later.

## Final Principle

This project must be built as a real commercial product, not as a temporary training project.
