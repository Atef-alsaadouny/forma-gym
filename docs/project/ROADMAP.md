# Project Roadmap

## Phase 1: Foundation

- Documentation
- Laravel setup
- Authentication
- Roles and permissions
- Base layout
- Database foundation

## Phase 2: Core Gym Operations

- Members
- Trainers
- Branches
- Packages
- Subscriptions
- Attendance

## Phase 3: Experience

- Public website
- Member dashboard
- Trainer dashboard
- Notifications

## Phase 4: Reporting

- Revenue reports
- Attendance reports
- Subscription expiry reports
- Member growth

## Phase 5: SaaS Readiness

- Tenant isolation
- Gym onboarding
- Per-gym settings
- SaaS billing

## Final Principle

Do not jump to advanced features before the operational core is stable.
