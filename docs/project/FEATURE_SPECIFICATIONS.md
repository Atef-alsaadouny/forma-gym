# Feature Specifications

## Public Website

Includes hero section, features, packages, trainers, branches, schedule, mobile app preview, and footer.

## Admin Dashboard

Admin can manage members, trainers, branches, packages, subscriptions, attendance, and reports.

## Member Area

Members can view subscription, training plan, measurements, attendance, and notifications.

## Trainer Area

Trainers can view assigned members, schedules, programs, and progress records.

## Future Features

- Online payments
- QR check-in
- Mobile app API
- Multi-gym SaaS billing
- AI coach recommendations

## Final Principle

Features must be implemented only when their business workflow is clear.
